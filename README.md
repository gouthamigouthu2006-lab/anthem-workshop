Four Things We Learned

- Git users: Each team member can configure a separate Git username and email.
- Collaboration: "git pull" brings the latest team changes into your local repository, while "git push" sends your committed changes to GitHub.
- Branching: Branches allow team members to work on separate features without directly changing the main branch.
- Merge conflicts: When two branches change the same lines, Git asks the team to resolve the conflict before completing the merge.
